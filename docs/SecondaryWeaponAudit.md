# サブ武器の公開情報照合

2026-10-31 / project/glyphica-android

[公式Wiki](https://alias.black/glyphica/wiki_english.html)で発動条件・進化・通常強化を照合する。ゲーム中の外観は、全11種を[公式ゲーム画像・映像とWebデモ](WeaponActorAppearance.md)へ個別に対応させる。カードの武器アイコンと実際の攻撃体は別の表現である。

## 武器ごとの実装

| 武器 | 公開されている基本挙動 | 本作の実装 |
| --- | --- | --- |
| Spectre | a/e/oを含む完成語から、文字数分の高速近接ドローン | 細い軌跡だけで表示。近接型も中央から移動し、敵へ旋回して飛び続ける |
| Sentry | 範囲内へ自動射撃するタレット | 自機外周の小三角が照準に旋回。小さい輪とその残像を持つ弾を撃つ |
| Tesla Mine | b/c/d/eで始まる完成語から、電撃D.O.T.タレット | 三角形の縁取り・範囲円・折れ線の電撃。設置最低5秒間隔と寿命32秒は本作の調整 |
| Oscillator | 最後の標的方向へ揺れる粒子の流れ | 小円の粒子列。Repeaterの長い直線トレイルを共有しない |
| Meteor | ランダム位置の照準の語を完成すると軌道爆撃 | 4つの円弧と4本の線で照準を表示。斜め上からの線と広がる爆発 |
| Hunter | i/o/uを含む完成語から文字数分の電撃ビームドローン | 細長い三角形の輪郭。敵の射程へ移動し、先端から電撃を反復照射 |
| Chopper | 主武器の発射で回転刃が画面端へ進む | 長い対向2枚刃と回転残像。Repeaterはバーストごとに1枚を発射 |
| Minefield | f/g/h/iで始まる完成語から接触爆発する低速地雷 | 中心小円と3本スポーク、薄い円。ゆっくり移動して接触爆発 |
| Blade Trap | j/k/l/mで始まる完成語から4本スポークの罠 | 中心輪と4本の長い棒状の刃・先端が回転する |
| Orbiter | n/o/p/qで始まる完成語から公転オーブ | 完成した敵の地点から自機中心に公転。大きい半透明の球と円の残像・破線 |
| Guardian | 燃料を消費する常設ドローン。実映像・Webデモでは自身の周囲の火球で接触攻撃 | 円形コア・方向の切り抜き・対向する2火球・軌道・残像・燃料バー。護衛範囲内の敵を追い、燃料切れで停止 |

## 根拠と数値

- 公式Wikiの武器アイコン字形は[編集可能なSVG](GlyphicaIconAssets.md)に変換済み。これはカードと装備枠に使う。全11種の攻撃体の形状・参照クラス・専用SVGは[武器アクターの外観](WeaponActorAppearance.md)を正本とする。
- [日本語WikiのSentry](https://wikiwiki.jp/glyphica/%E3%82%BB%E3%83%B3%E3%83%88%E3%83%AA%E3%83%BC)の30ダメージ・86ヒット/分・40m・343.8度/秒を参照。本作の射程80dpは独立した画面設定。
- [Tesla Mine](https://wikiwiki.jp/glyphica/%E3%83%86%E3%82%B9%E3%83%A9%E3%83%9E%E3%82%A4%E3%83%B3)のWikiページには設置間隔や寿命が載っていない。一方、[公式Webデモ](https://playglyphica.com/)の配信スクリプトには武器の基礎値と描画処理が存在する。公開値の有無をWikiだけで判断しない。デモのフレーム単位とSteam版の秒数、本作のdpは同一と扱わない。
- GuardianのWiki文はレーザーだが、[公式紹介映像](https://clan.fastly.steamstatic.com/images/44862715/e82a750f09dfde8ba44c3c9863e530be33e0cd22.gif)と公開デモのGuardianDroneは周回する火球で一致する。今回の実装はこの実物を採用し、レーザーとプレイヤー中心の公転を組み合わせた描画を撤去した。
- 本作の具体的な調整値は[LevelUpDesign.md](LevelUpDesign.md)に集約する。未照合の速度・持続・間隔・dp寸法をSteam版の確定値とは呼ばない。状態異常の数値を、同じ属性の武器本体の基礎値へ流用しない。
