# サブ武器の公開情報照合

2026-10-31

公式Wiki、Glyphica開発者のSteam告知、日本語の有志Wiki、公開スクリーンショットを照合した。原作の発動条件と基本挙動は公式Wikiを優先し、個別画像は公式Wikiの武器アイコン字形とSteamのゲーム画面を参照する。公式Wikiの武器アイコンは[編集可能なSVG](GlyphicaIconAssets.md)へ変換済み。カードと装備枠にはこの公式字形を使い、ゲーム中の攻撃体は各武器の挙動が読める形で別に描く。

## 画像と性能の扱い

- [公式Wiki](https://alias.black/glyphica/wiki_english.html)は11種の発動条件、分類、進化と相対アップグレードを掲載する。各武器の基礎ダメージ、寿命、発動間隔は多くのページに載っていない。
- [日本語有志WikiのTesla Mine](https://wikiwiki.jp/glyphica/%E3%83%86%E3%82%B9%E3%83%A9%E3%83%9E%E3%82%A4%E3%83%B3)、[Sentry](https://wikiwiki.jp/glyphica/%E3%82%BB%E3%83%B3%E3%83%88%E3%83%AA%E3%83%BC)、[状態異常](https://wikiwiki.jp/glyphica/%E7%8A%B6%E6%85%8B%E7%95%B0%E5%B8%B8)を参照した。Sentryは基礎値が表で公開されているが、Tesla Mineの出現間隔・持続時間は載っていない。状態異常D.O.T.の値をTesla Mine本体の基礎ダメージとは扱わない。
- [Steam開発者告知](https://store.steampowered.com/news/posts/?enddate=1748424987&feed=steam_community_announcements)はGuardianを周回する近接Heat攻撃として紹介している。現行[公式Wiki](https://alias.black/glyphica/wiki_english.html)のレーザー説明と記述が異なるため、ゲーム内は現行Wikiのレーザーを採り、周回の見せ方を開発告知から取り入れた。
- [Steam公式スクリーンショット](https://store.steampowered.com/app/2400160/Glyphica_Typing_Survival/)と[SteamDBのスクリーンショット一覧](https://steamdb.info/app/2400160/screenshots/)を形状・色使いの参考にした。画像検索で見つかる攻略画面は武器の存在や画面内表現の照合に使い、基礎数値の根拠にはしない。

Teslaの薄い三角形アウトラインは、カードの公式武器アイコンとは別の設置体シルエットで、`app/src/main/res/raw/weapon_actor_tesla_mine.svg` にある。武器追加時はまず公式説明から発動契約と相対アップグレードを取り込み、絶対値がない場合は試作値として個別の調整値に置き、出典のある値と混同しない。
