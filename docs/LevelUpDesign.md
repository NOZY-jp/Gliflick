# レベルアップ選択と11種のサブ武器

2026-10-30 / project/glyphica-android

## 目的と画面

原作の横3列を、IME表示中のスマホでは縦3枚へ変更する。温かい白・薄い灰・インク色・くすんだ赤を使い、武器名、分類、効果、選択語を各カードにまとめる。横幅660dp超の横長画面では横3列となる。カードの幾何は描画とタップで共用する。

カード・装備枠には[公式アイコンのSVG](GlyphicaIconAssets.md)を使う。Repeaterの進化カードは進化枝ごとのアイコンを表示する。ゲーム中の攻撃体は[全11種の外観仕様](WeaponActorAppearance.md)に従い、専用のSVGと軌跡・粒子・電撃で描く。

経験値でレベルが上がると、プレイヤーの上に `レベルアップ [␣] ×n` を表示する。Spaceで報酬を一つ開き、カードはタップまたは下部の語で選択する。複数レベル分の報酬は一つずつ開く。進化報酬も同じSpace操作で開き、通常レベルアップより先に処理する。選択中は戦闘時刻、敵、弾、ドローン、設置物、燃料、状態異常、バフ時間を停止する。タップは50ms/字の入力表示、完成後は250msで戦闘へ戻る。リロールは一周3回で、選択中にSpaceまたは画面下部ボタンで実行する。

入力は既存のGameImeEditTextとWordMatchEngineを使う。画面の出入り・リロール時は入力世代を更新してIMEの未確定バッファを消す。戦闘で既に判定済みの途中進捗・ストリークを保持し、選択語を戦闘へ流さない。選択語は3字、語頭の仮名と標準ローマ字の頭文字を重複させない。

## 責務と追加方法

| 要素 | 責務 |
| --- | --- |
| WeaponCatalog / UpgradeOffer | 武器分類、名称、取得条件、強化の数値データ |
| WeaponRunState | 一周の加算補正、武器レベル、撃破・進化カウント |
| SecondaryWeapon / BaseSecondary | 取得時、単語完成時、毎tick、ピックアップ使用時の契約 |
| 武器ごとのController | 発動条件と生成する攻撃 |
| WeaponActor派生クラス | 移動、照準、当たり判定の問い合わせと攻撃間隔 |
| CombatWorld | 共通ダメージ、撃破帰属、XP、状態異常、攻撃とピックアップの寿命 |
| CombatSession / UpgradeSelection | 報酬キュー、選択語、ゲーム停止、既存入力判定との接続 |
| UpgradeLayout / UpgradeRenderer | 配置、ヒット領域、表示。武器効果を計算しない |
| SecondaryWeaponRenderer / WeaponIconRenderer | ネイティブのベクター記号、攻撃描画、4枠HUD |

新武器はWeaponIdの説明とFactoryへの登録、SecondaryWeapon実装、必要な強化データを追加する。IMEやActivityへ武器別分岐を追加しない。新しい攻撃形態はWeaponActorを追加し、共通ダメージ経路を使う。

## リピーターの通常強化

名称と数値は公式Wikiと日本語Wikiを照合した。倍率は加算型として一周に累積し、発射される弾へ反映する。

| 系統 | コモン | アンコモン | レア |
| --- | --- | --- | --- |
| 進化カウント | 知識の増幅 +10 | 戦闘データ +20 | 熟練の指導 +30 |
| ダメージ | フルメタル・ジャケット +10% | 徹甲弾アップグレード +20% | 貫通力強化 +30% |
| Crit | ターゲット力強化：率+1% / 倍率+50% | 精密誘導システム：率+2% / 倍率+100% | イーグルアイ：率+3% / 倍率+200% |

爆発弾取得後はペイロードブースター（爆発範囲+25%）も出現する。貫通力強化という名称でも通常強化の効果はダメージ+30%であり、貫通を追加するものではない。

進化カウントは当該武器の実撃破と進化カウント強化で増える。Repeaterは累計50、100、150…ごとに別の進化選択を開く。50刻みはSteamコミュニティガイドの記載で、公式Wikiの確定した閾値ではない。

| 進化 | I | II |
| --- | --- | --- |
| ショットガン | 発射体+5、基礎ダメージ−10、拡散 | 発射体さらに+5、拡散を拡大 |
| 跳弾 | 近くの別の敵へ3回、2体目以降は初期ダメージの50% | 跳弾回数さらに+2 |
| フロストファング | 冷気ダメージ+10、凍結確率3% | 冷気+20、キネティック−10 |
| 爆発弾 | 爆発+10、キネティック−10、命中点で範囲攻撃 | 爆発+15、キネティック−10、基礎爆発範囲を拡大 |

進化の加算量は公開値を使い、未公開の基礎散角、跳弾索敵距離、凍結時間、距離のdp変換は試作値。複合属性のダメージは現行の整数HPモデルでは合算し、凍結確率と爆発半径を別に保持する。跳弾と爆発が両方ある場合は両方動く。

## 現行11種の基本挙動

サブ武器は最大4種。取得済み武器と、満員時の新武器は新規取得候補から除く。取得すると、その武器の通常強化が抽選プールへ入る。通常強化は公開表にあるダメージ、範囲、持続時間、連射・回転、移動速度など、現在の基本挙動へ実際に作用する項目を収録した。全サブ武器の進化ツリーや、それを前提とする強化は今回のプールに含めない。

| 武器 | 発動条件と実装 |
| --- | --- |
| スペクター | 完成語中のa/e/oの数だけ近接ドローン。速度を維持して敵へ旋回し、接触して反復攻撃。移動履歴を軌跡として描く |
| セントリー | 取得時に中央へ常設。射程内の近い敵へ旋回し、照準が合ってから自動射撃 |
| テスラマイン | b/c/d/eで始まる語。設置した範囲内へ周期的な電撃 |
| オシレーター | 自動で揺れる粒子列。完成した最後の敵の方向へ発射 |
| メテオ | 定期的な独立照準マーカー。その語を完成すると地点を数回爆撃 |
| ハンター | 完成語中のi/o/uの数だけドローン。距離を保ち電撃ビームを反復照射 |
| チョッパー | 主武器の各バースト開始時に回転刃。発射方向へ直進して画面端へ抜け、経路上を攻撃 |
| マインフィールド | f/g/h/iで始まる語。ゆっくり放射状に移動し、接触すると範囲爆発 |
| ブレードトラップ | j/k/l/mで始まる語。四つの刃が回転し、刃に触れた敵へ反復攻撃 |
| オービター | n/o/p/qで始まる語。自機の周囲を回転し、軌道上を接触攻撃 |
| ガーディアン | 取得時に常設。護衛範囲内の敵を追い、自身の周囲を回る2個の火球で接触攻撃。燃料が空なら停止し、燃料語で再始動 |

文字条件は公式英語Wikiの文字群を採用する。日本語では辞書の読みをTypingLanguage.defaultRomanへ渡した標準表記を条件に使う。物理的なローマ字入力の復元ではなく、入力方法に依存しない本作の発動ルールである。別綴りの選択やフリック入力で出現数が変わらず、この表記を入力判定へ戻さない。原作日本語版の専用文字割当てと同一とは確認していない。

メテオ照準・燃料の語も戦闘の共有matcherへ参加する。ピックアップの語は武器の標的化・Repeater発射・サブ武器再発動には使わない。期限切れで語を除去してもミスタイプを作らない。

## 公開値と試作設定

セントリーの30ダメージ、86ヒット/分、40m射程、343.8度/秒は日本語Wikiの値。射程を80dp、旋回を6rad/秒にした。以下のdp寸法・速度・秒数・間隔は本作の調整値である。公式Wikiの表に載っていない基礎値も公式Webデモの配信スクリプトには存在するが、フレーム単位・画面換算とSteam版の版差を確認せず同じ値とは扱わない。

| 武器 | 基礎ダメージ | 持続・間隔・速度・範囲の基準値（エリア型のサイズは下記補正） |
| --- | ---: | --- |
| スペクター | 50 | 7秒、75dp/秒、接触0.55秒間隔 |
| テスラマイン | 12 | 32秒、半径38dp、0.5秒間隔。設置は有効語完成後に5秒の最低間隔 |
| オシレーター | 10 | 0.16秒間隔、230dp/秒、揺れ幅0.3rad |
| メテオ | 80 | 初回2秒、以後9秒、半径40dp、2.2秒間の0.35秒間隔攻撃 |
| ハンター | 10 | 7秒、75dp/秒、射程70dp、0.3秒間隔 |
| チョッパー | 24 | 150dp/秒、半径24dp、同じ敵は0.22秒間隔 |
| マインフィールド | 150 | 14秒、18dp/秒、爆発半径30dp |
| ブレードトラップ | 5 | 10秒、刃長28dp、4rad/秒、接触0.16秒間隔 |
| オービター | 70 | 10秒、完成した敵の位置から自機中心の軌道、球半径10dp、1.8rad/秒、同じ敵は0.5秒間隔 |
| ガーディアン | 20 | 初期燃料30秒、護衛範囲70dp、48dp/秒、火球接触は同じ敵に0.1秒間隔。燃料は12秒周期、補給20秒、上限60秒 |

2026-10-31のサイズ調整で、Tesla Mine・Meteor・Chopper・Minefield・Blade Trap・Orbiter・Guardianに`WeaponSizeTuning.AREA_WEAPON_SCALE = 1.5`を適用。現在の実効半径／刃長は順に57・60・36・45・42・15・105dp。本体の描画、範囲円、残像、爆発、接触判定に同じ倍率を使い、通常の範囲強化はこの補正後に乗算する。Orbiterは球を大きくし、公転経路は完成した敵との距離を維持する。記録は[エリア型のサイズ確認](verification/area-size-20261031/README.md)。

テスラマイン／ブレードトラップの設置点は、自機から入力した敵へ65%進んだ画面内の点。メテオ・燃料マーカーは端から余白を置いてランダム配置。Teslaの5秒設置間隔と32秒寿命は原作の公開基礎値ではなく、頻度と見た目を抑えるための試作値。根拠と武器別の照合結果は[サブ武器照合ノート](SecondaryWeaponAudit.md)を参照。

出血・発火・ブライトは基礎10ダメージ、0.5秒間隔、5秒。スタティックは基礎3ダメージ、0.5秒間隔、5秒で近くにも連鎖する。これらの数値は日本語Wikiの状態異常表。通常の状態付与率3%、冷気凍結2秒、ブライト中60%速度、スタティック半径30dpは試作設定。D.O.T.は現段階でCritしない。

ダメージ履歴を10秒窓で集計して選択画面のDPSへ使う。自動攻撃・状態異常・爆発・跳弾も撃破帰属とXPの共通経路を通る。負荷上限は武器ごと48個、合計160個のactor、弾1024個、短いエフェクト160個。敵の16体上限とは別の描画負荷対策である。候補のレアリティ抽選重み14:5:1、Spaceで開く報酬キュー、リロール3回は本作の設定。

## 検証と完了条件

単体では複数報酬の保留、時間停止、選択入力の分離、リロール枯渇、4枠と重複除外、11種の実ダメージ、燃料切れと補給、進化カウントと発射効果、跳弾／爆発、仮名とローマ字で同じ武器発動、320dp幅と短い画面の配置を確認する。

Pixel 7aでは実際のIMEを出した画面を撮影し、タップ取得、ローマ字合成入力での途中色と選択、リロール、進化選択、取得済み武器描画を確認する。自動InputConnection通知は人のSimeji打鍵を証明するものではない。結果と画像は[実機確認記録](verification/levelup-20261030/README.md)へ保存する。
