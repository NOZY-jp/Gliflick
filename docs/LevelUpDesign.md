# レベルアップ選択と11種のサブ武器

2026-10-30 / project/glyphica-android

## 目的と画面

原作の横3列を、IME表示中のスマホでは縦3枚へ変更する。温かい白・薄い灰・インク色・くすんだ赤を使い、武器名、分類、効果、選択語を各カードにまとめる。横幅660dp超の横長画面では横3列となる。カードの幾何は描画と配置で共用する。報酬カードのタップでは入力・選択を行わない。

カード・装備枠には[公式アイコンのSVG](GlyphicaIconAssets.md)を使う。Repeaterの進化カードは進化枝ごとのアイコンを表示する。ゲーム中の攻撃体は[全11種の外観仕様](WeaponActorAppearance.md)に従い、専用のSVGと軌跡・粒子・電撃で描く。

経験値でレベルが上がると、プレイヤーの上に `レベルアップ ×n [␣]` を表示する。最初のSpaceで報酬を開き、カードは下部の語を入力して選択する。その後は未消費の進化・レベルアップがなくなるまで次の選択を自動表示する。進化報酬も同じSpace操作で開き、通常レベルアップより先に処理する。選択中は戦闘時刻、敵、弾、ドローン、設置物、燃料、状態異常、バフ時間を停止する。報酬のタップ自動入力は廃止し、入力完成後250msで効果を適用し、残りがあれば次の選択へ、すべて消費したら戦闘へ戻る。連続時は次のパネルの初期フェードを省き、背後の戦闘画面を一瞬露出させない。各選択の境界でIME入力世代を更新し、選択語を次へ流さない。タイトルのタップ操作は別仕様のまま。リロールは初期3回で、敵が落とすダイスの語を入力して追加できる。選択中にSpaceまたは画面下部ボタンで実行する。

入力は既存のGameImeEditTextとWordMatchEngineを使う。画面の出入り・リロール時は入力世代を更新してIMEの未確定バッファを消す。戦闘で既に判定済みの途中進捗・ストリークを保持し、選択語を戦闘へ流さない。選択語は3字、語頭の仮名と標準ローマ字の頭文字を重複させない。

## 到達・進化のフィードバック

レベルが上がった時はメイン武器中心、進化段階に到達した時と進化を適用した時は対象武器の装備枠中心へ、灰色のリングを収束させる。対象を中心とした最遠の画面角までの距離より大きい半径から開始し、0.58秒のcubic ease-inで縮小、0.12秒の放物線で向きを滑らかに反転し、0.58秒のcubic ease-outで画面外の元半径まで拡大する。収縮末尾と拡大開始の速度を一致させ、各区間の接続速度も連続にする。最小半径を通過してから不透明度65%から0%へ。全体1.28秒。レベル到達時の半径は自機半径+7dp、装備枠は18dpを基準とする。

RewardFeedbackは描画用の時間とポーズだけを所有し、CombatSessionが到達/適用時に生成する。同じ段階を毎フレーム再通知せず、消費・リロールによって到達演出を再発生させない。戦闘停止中も選択UIと演出の表示時計は進む。ArsenalLayoutをアイコン描画とリングで共有し、装備順・幅・高さ変更へ追従する。再開時に実時間の経過をまとめて進めない。

通知の末尾は「レベルアップ ×n」の後に灰色の角丸背景と背景色の␣を置く。アイコン全体だけを1.4秒周期で0→100→0%に滑らかに点滅させ、ラベルと数は点滅させない。進化のみ/混在時の既存通知ラベルは維持する。

## 責務と追加方法

| 要素 | 責務 |
| --- | --- |
| WeaponCatalog / UpgradeOffer | 武器分類、名称、取得条件、強化の数値データ |
| WeaponRunState | 一周の加算補正、武器レベル、撃破・進化カウント |
| SecondaryWeapon / BaseSecondary | 取得時、単語完成時、毎tick、ピックアップ使用時の契約 |
| 武器ごとのController | 発動条件と生成する攻撃 |
| WeaponActor派生クラス | 移動、照準、当たり判定の問い合わせと攻撃間隔 |
| CombatWorld | 共通ダメージ、撃破帰属、XP、状態異常、攻撃とピックアップの寿命 |

新武器はWeaponIdの説明とFactoryへの登録、SecondaryWeapon実装、必要な強化データを追加する。IMEやActivityへ武器別分岐を追加しない。新しい攻撃形態はWeaponActorを追加し、共通ダメージ経路を使う。

## リピーターの通常強化

名称と数値は公式Wikiと日本語Wikiを照合した。倍率は加算型として一周に累積し、発射される弾へ反映する。

| 系統 | コモン | アンコモン | レア |
| --- | --- | --- | --- |
| 進化カウント | 知識の増幅 +10 | 戦闘データ +20 | 熟練の指導 +30 |
| ダメージ | フルメタル・ジャケット +10% | 徹甲弾アップグレード +20% | 貫通力強化 +30% |
| Crit | ターゲット力強化：率+1% / 倍率+50% | 精密誘導システム：率+2% / 倍率+100% | イーグルアイ：率+3% / 倍率+200% |

爆発弾取得後はペイロードブースター（爆発範囲+25%）も出現する。貫通力強化という名称でも通常強化の効果はダメージ+30%であり、貫通を追加するものではない。

進化カウントは当該武器の実撃破と進化カウント強化で増える。全武器は累計50・150・300で最大3回進化選択を開く。公式公開デモの段階ごとの必要数50→100→150を確認した。[全武器の進化設計](WeaponEvolutionDesign.md)を参照。

| 進化 | I | II |
| --- | --- | --- |
| ショットガン | 発射体+5、基礎ダメージ−10、拡散 | 発射体さらに+5、拡散を拡大 |
| 跳弾 | 近くの別の敵へ3回、2体目以降は初期ダメージの50% | 跳弾回数さらに+2 |
| フロストファング | 冷気ダメージ+10、凍結確率3% | 冷気+20、キネティック−10 |
| 爆発弾 | 爆発+10、キネティック−10、命中点で範囲攻撃 | 爆発+15、キネティック−10、基礎爆発範囲を拡大 |

進化の加算量は公開値を使い、未公開の基礎散角、跳弾索敵距離、凍結時間、距離のdp変換は試作値。複合属性のダメージは現行の整数HPモデルでは合算し、凍結確率と爆発半径を別に保持する。跳弾と爆発が両方ある場合は両方動く。

## 現行11種の基本挙動

サブ武器は最大4種。取得済み武器と、満員時の新武器は新規取得候補から除く。取得すると、その武器の通常強化が抽選プールへ入る。通常強化は公開表にあるダメージ、範囲、持続時間、連射・回転、移動速度など、現在の基本挙動へ実際に作用する項目を収録した。全11サブ武器の43進化枝と進化カウント強化も実装する。前提システムのない盾破壊・Splatter Shot専用進化は候補から除く。各武器の進化と外観は[進化設計](WeaponEvolutionDesign.md)を参照。

| 武器 | 発動条件と実装 |
| --- | --- |
| スペクター | 完成語中のa/e/oの数だけ近接ドローン。速度を維持して敵へ旋回し、接触して反復攻撃。移動履歴を軌跡として描く |
| セントリー | 取得時に中央へ常設。射程内の近い敵へ旋回し、照準が合ってから自動射撃 |
| テスラマイン | b/c/d/eで始まる語。設置した範囲内へ周期的な電撃 |
| オシレーター | 自動で揺れる粒子列。完成した最後の敵の方向へ発射 |
| メテオ | 定期的な独立照準マーカー。その語を完成すると地点を数回爆撃 |
| ハンター | 完成語中のi/o/uの数だけドローン。距離を保ち電撃ビームを反復照射 |
| チョッパー | 主武器のバースト開始時、空き枠がある場合に回転刃を一つ発射。通常1枠、Dual Wieldで2枠。稼働中の各飛行が終了するまでその枠を使う。発射方向へ直進して画面端へ抜け、経路上を攻撃 |
| マインフィールド | f/g/h/iで始まる語。ゆっくり放射状に移動し、接触すると範囲爆発 |
| ブレードトラップ | j/k/mで始まる語。四つの刃が回転し、刃に触れた敵へ反復攻撃 |
| オービター | n/o/pで始まる語。自機の周囲を回転し、軌道上を接触攻撃 |
| ガーディアン | 取得時に常設。護衛範囲内の敵を追い、自身の周囲を回る2個の火球で接触攻撃。燃料が空なら停止し、燃料語で再始動 |

文字条件の基礎は公式英語Wikiを参照し、日本語標準ローマ字で成立しない語頭l/qと追加文字vを除外する。追加進化の文字群はy/zとw。WeaponTriggerGlyphsを説明と処理で共有し、実辞書の2〜7文字語で各条件の成立をテストする。日本語では辞書の読みをTypingLanguage.defaultRomanへ渡した標準表記を条件に使う。物理的なローマ字入力の復元ではなく、入力方法に依存しない本作の発動ルールである。別綴りの選択やフリック入力で出現数が変わらず、この表記を入力判定へ戻さない。2026-11-02に公開デモのjapanese.triggersも取得し、英語の文字群がそのまま含まれていたが、日本語での実用性を保証しないことに注意する。Steam現行版の全入力ロケールの挙動まで保証するものではない。

メテオ照準・燃料の語も戦闘の共有matcherへ参加する。ピックアップの語は武器の標的化・Repeater発射・サブ武器再発動には使わない。期限切れで語を除去してもミスタイプを作らない。

## 公開値と試作設定

セントリーの30ダメージ、86ヒット/分、40m射程、343.8度/秒は日本語Wikiの値。射程を80dp、旋回を6rad/秒にした。以下のdp寸法・速度・秒数・間隔は本作の調整値である。公式Wikiの表に載っていない基礎値も公式Webデモの配信スクリプトには存在するが、フレーム単位・画面換算とSteam版の版差を確認せず同じ値とは扱わない。

| --- | ---: | --- |
| スペクター | 50 | 7秒、75dp/秒、接触0.55秒間隔 |

2026-10-31のサイズ調整で、Tesla Mine・Meteor・Chopper・Minefield・Blade Trap・Orbiter・Guardianに`WeaponSizeTuning.AREA_WEAPON_SCALE = 1.5`を適用。現在の実効半径／刃長は順に57・60・36・45・42・15・105dp。本体の描画、範囲円、残像、爆発、接触判定に同じ倍率を使い、通常の範囲強化はこの補正後に乗算する。Orbiterは球を大きくし、公転経路は完成した敵との距離を維持する。記録は[エリア型のサイズ確認](verification/area-size-20261031/README.md)。

スペクター／ハンター／テスラマイン／ブレードトラップ／入力発動のマインフィールド／オービターは、完成した敵の位置から生成する。メテオ・燃料マーカーは端から余白を置いてランダム配置。Teslaの独自5秒発動制限は撤去。32秒寿命は引き続き本作の試作値。Hunterの基礎10・120回/分・活動350フレームは公開デモのHunter/HunterDroneから採用。ビームは射程・照準条件を満たす間表示し、ダメージだけ周期判定する。Electrified Boltsでは周期を2倍にする。ChopperのSaw Launcherでは一斉発射した鋸の全てが終了するまで1枠を占有し、Dual Wieldを同時発射数として扱わない。根拠と武器別の照合結果は[サブ武器照合ノート](SecondaryWeaponAudit.md)を参照。

出血・発火・ブライトは基礎10ダメージ、0.5秒間隔、5秒。スタティックは基礎3ダメージ、0.5秒間隔、5秒で近くにも連鎖する。これらの数値は日本語Wikiの状態異常表。通常の状態付与率3%、冷気凍結2秒、ブライト中60%速度、スタティック半径30dpは試作設定。D.O.T.は現段階でCritしない。

ダメージ履歴を10秒窓で集計して選択画面のDPSへ使う。自動攻撃・状態異常・爆発・跳弾も撃破帰属とXPの共通経路を通る。負荷上限は武器ごと48個、合計160個のactor、弾1024個、短いエフェクト160個。敵の16体上限とは別の描画負荷対策である。候補のレアリティ抽選重み14:5:1、Spaceで開く報酬キュー、初期リロール3回は本作の設定。追加ドロップは[BossAndRerollDesign.md](BossAndRerollDesign.md)を参照。

## 検証と完了条件

単体では複数報酬の保留、時間停止、選択入力の分離、リロール枯渇、4枠と重複除外、11種の実ダメージ、燃料切れと補給、進化カウントと発射効果、跳弾／爆発、仮名とローマ字で同じ武器発動、320dp幅と短い画面の配置を確認する。

Pixel 7aでは実際のIMEを出した画面を撮影し、当時のタップ取得、ローマ字合成入力での途中色と選択、リロール、進化選択、取得済み武器描画を確認する。自動InputConnection通知は人のSimeji打鍵を証明するものではない。結果と画像は[実機確認記録](verification/levelup-20261030/README.md)へ保存する。

2026-11-02の修正は[発動ルール再照合](WeaponActivationAudit.md)と[エミュレーター確認](verification/weapon-rules-20261102/README.md)を参照。報酬カードのタップ無効、入力選択、重なりの優先描画を現仕様として確認する。

## 発動条件の表示基準（2026-11-05）

文字条件は「読みの標準ローマ字表記が、指定文字で始まる／指定文字を含む」と説明する。ワンストローク入力モードの画面表記は仮名であり、ローマ字表記のモードとは呼ばない。実際の打鍵や入力中に選ばれた別綴りではなく、TypingLanguage.defaultRomanによる固定表記が基準。仮名入力でも同じ基準を使う。じかんはjikann/zikann/じかんのいずれで完成してもjから始まる語として扱い、ちずはchizu/tizu/ちずのいずれでもcから始まる語として扱う。取得カードと追加文字の進化カードは同じ表示文を使う。語頭を仮名へ置き換える仕様変更はしない。
