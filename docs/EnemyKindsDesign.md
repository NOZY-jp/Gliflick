# 敵種の拡張

2026-11-02。対象はShield Drone / Shooter / Shooter Missile / Warder / Warder Barrier / Splitter。既存Droneのなめらかなティア進行と変異、ランダム到着、入力・ストリーク、武器進化を維持する。

## 構造と受入条件

固定性能はEnemyCatalog、移動と発射要求はEnemyBehavior、耐久はDurability、攻撃・生成・破壊はCombatWorld、字形とバリアはEnemyRendererへ分離する。画像を貼らず、Wiki画像を照合した編集可能SVGと同じ幾何で描く。

Splitterは部品ごとにHPと衝突円を持つ。一体の入力対象として移動・回転し、最初の部品が壊れると残りが独立する。残HPと部品に付いていたD.O.T.の残時間・周期を保持し、親の語は通常の死亡規則で退役する。単なるHP合算の敵や、全回復した子を死亡時に増殖させる方式を使わない。合体中の部品も生存枠へ数え、分離して16を超えない。

WarderBarrierは所有者付きの別エンティティ。回転する120°の弧だけ弾を消し、弧の裏から本体を撃てる。周囲の非Warderを無敵にし、重なる保護の一方が死んでも残る所有者の保護を維持する。所有者死亡と同時に弧・保護を消す。範囲・近接・D.O.T.も共通ダメージ経路で保護される。

ShieldはHPとは別に吸収・超過分の貫通・回復を持つ。Shooterは画面外から進み端近くへ配置後に発射する。ミサイルは打ち落とせる敵で、自機へ発射方向を固定して進み、撃破・接触に通常の入力退役処理を使う。

## 出典と採用

- [公式Wiki](https://alias.black/glyphica/wiki_english.html) — 各敵HP・シールド・接触ダメージ、Splitter部品数と部品HP、外形画像。
- [公式公開デモ](https://playglyphica.com/glyphica/index.html)の[配信スクリプト](https://playglyphica.com/glyphica/dist/scripts/core/main.js) — Spawner、Enemy、ShieldDrone、Shooter/Cube、Splitter/Shard、Warder/RotatingShield。取得ソースは無視対象build内のみ。

Shield DroneはHP100/200/400/800/2400、Shield200/400/800/1600/4800、接触50/100/150/200/250。デモの被弾後30フレーム待機・毎フレーム2回復を、60fpsで0.5秒・120/秒へ換算。

ShooterはHP300/600/1200/2400/7200・接触25。デモは発射周期600フレーム＝10秒、初回50〜150フレーム、ミサイルの準備420フレーム＝7秒。ミサイル性能は公開デモのShooterCube系を照合し、最初の設計書の「Drone相当という想定」と分ける。

Splitterは4/5/6部品、部品HP350/500/650、接触40。最初の部品を破壊すると残部品が分離する。WarderはHP300、近くの非Warderを保護。バリア120°はユーザー指定を優先する（デモは難易度により約117°または90°）。

公開デモの適応値・Threat予算・抽選表は確認済み。2026-11-05のユーザー指定により、種別の登場時刻と到着率は本作の設定へ変更した。公開表は種内ティアの相対分布だけへ利用し、特殊/エリート上限は適用しない。Droneのティアは独立した時間・レベル分布を維持する。

未公開のSteam現行版一致を保証せず、画面dp換算と展開位置・速度は既存のスマホ用スケールに合わせる。検証では全敵種の通常・境界ケースと、エミュレーター上の実画面を確認する。

## 種別の登場時刻と到着率（2026-11-05）

開始60秒まではDroneのみ。60秒を超えたらShield Droneの割合を低確率からsmoothstepで増やし、240秒で通常2種のDrone : Shield Droneを2 : 1へ到達させ、その後固定する。150秒を超えたらShooter / Splitter / Warderを解禁する。空き枠がある場合の平均到着間隔はそれぞれ15秒 / 30秒 / 90秒。固定タイマーではなく、各種の到着率を合算したPoisson抽選で一回一体ずつ登場する。

通常2種の合計到着率は既存の0.45体/秒を基準に120秒の波とレベル補正を適用する。特殊3種はこれに独立して加算し、波・レベルによって指定平均を変えない。16体の生存枠、合体Splitter全部品の枠消費、Shooterの射撃用予約枠は維持する。収まらない候補の到着率を取り除き、他種へ振り替えたり、後でまとめて出したりしない。このため満員時の実際の登場間隔は長くなる。

公開デモの適応値は60fps換算で`f = 経過秒 × 60`、`F = max(f, (2^(0.000025 × f) - 1.6) × プレイヤーレベル × 3600)`。Threat予算`floor(30 + 0.0045F)`を保持する。元デモの特殊/エリート上限値も参照用に計算するが、出現制御には使用しない。17段階の元表は各種の内部で正規化したティア比率だけへ利用し、新しく早期解禁された種に元表の候補がまだなければTier1とする。Droneのティアは独立した既存分布を使う。

設定・式・検証結果は[EnemyArrivalDesign.md](EnemyArrivalDesign.md)を参照。

## 画面換算・推定・意図的な差分

- 基準寸法は既存Drone半径4.5dpと公開デモの基準7単位から`UNIT=4.5/7`。移動は既存Droneの5.95dp/秒を保ち、公開デモの通常速度範囲0.4〜0.9の中心0.65を基準に他種の相対速度を換算する。このdp換算は本作の推定で、Steamの絶対速度ではない。
- Shieldは固定5.95dp/秒。Shooterは約13.73dp/秒で端へ進み、停止後は10秒周期。Missileは7秒準備後、約4.58dp/秒で固定方向へ進む。発生距離60/70/80/85/85単位、HP200/500/1000/2000/6000、接触40/80/160/320/320は公開デモ。準備中の弾は所有者死亡で消え、発進後は所有者と独立する。
- Warderは約9.15dp/秒で端へ進み、HP300。接触値はWikiにないため、端で停止する支援役として0とした。無敵範囲300単位≒192.9dp、バリア半径39単位≒25.1dp、厚さ5単位≒3.2dp、回転0.6rad/秒は公開デモを参照。120°はユーザー指定。
- Splitterは5.95dp/秒、回転1.2rad/秒。分離の0.5秒展開は公開デモ、放射距離12〜32dpは画面内で読めるようにした推定。分離後は約4.12dp/秒で進む。
- 円による身体・部品の衝突は輪郭の近似。バリアは円弧帯のスイープと端点の近似円を使い、高速弾が帯を飛び越えて当たることを防ぐ。描画の弧端は角丸にしない。
- 原作にない16部品上限の下で、通常出現が射撃を完全に止めないよう、Shooterが生存しミサイルが一つもない間だけ最後の1枠を射撃用に予約する。ミサイル自体も16に含む。これは小さい画面向け上限と両立させるための推定ルール。
- 設置位置は画面端から本体半径＋18dp内側。原作の画面サイズ・レーン予約は持ち込まず、文字は従来どおり敵へ追従し、上半分からの敵は文字を下、バーを上へ固定する。文字サイズ・バー幅24dpは個体サイズで変えない。

## SVGの編集

`app/src/main/res/raw/`の`enemy_shield_drone_1..5.svg`、`enemy_shooter_1..5.svg`、`enemy_shooter_missile_1..5.svg`、`enemy_warder.svg`、`enemy_splitter_shard_1..3.svg`が実描画の原本。`enemy_splitter_1..3.svg`は合体配置のプレビュー。実行時は同じ部品SVGを回転配置し、分離後も同じ大きさを保つ。バリア・保護の線・シールド/HPバーはEnemyRenderer/CombatRendererが動的に描く。敵本体は既存のくすんだ赤、バリアと保護・耐久バーは灰色基調。

参照画像は公式WikiのShieldDrone1〜5、Shooter1〜5、Splitter1〜3、Warderを個別に表示して照合した。画像そのものは製品へ貼らず、ベクターを独自に再構成する。

## Shooterの外形の訂正

追加の山形を本体の後ろへ置いた初期近似は誤り。Wiki画像では本体より先端側へ重なっている。全5ティアを画像の輪郭と部品の相対位置からSVGへ作り直し、全体の見た目の半径も同じ輪郭から求める。本体の衝突円15単位と見た目全体の半径を分離し、HPや発射性能は変えない。[元画像との照合手順と結果](verification/shooter-reference-20261102/README.md)を参照。

## ボス/UI拡張（2026-11-05）

ウォーダーの無敵範囲はprotectionRadiusの細い全周円で可視化する。画面内の生存所有者という有効条件は被ダメージ保護と共有し、対象の敵がまだいなくても円を描く。弾を消す120°の回転バリアとは別の描画である。
