Pixel 7aの更新後Canvasで制御状態を検証。保存画像はアプリ領域のみ。g→ごの検証は実InputConnectionへの合成通知であり、人のIME打鍵実測とは区別する。デコーダーは変更せず日本語の目標定義へ修正した。

旧ドロップ設定も120秒の殺害間ハザードであり、平均率が過剰になるバグは確認していない。短い連続間隔を抑えるため、平均120秒/標準偏差60秒のErlang(shape=4)待ちへ変更。期限を過ぎた実撃破で1個だけ出し、実時刻から次を抽選。同時撃破や長い無撃破後の積み残しは一括配布しない。単体では撃破間隔0.1/1/5秒を240000秒間ずつシミュレーションし、おおむね2000個（1840–2100）の率と30秒未満の間隔が5%未満であることを確認。10秒寿命は9.99秒で存続、10.01秒で語も消えることを確認。

全201単体テストとdebug/AndroidTest APKビルド成功。最終実機13件を一括成功（45.457秒）：ボス5、通常戦闘3、レベルアップ5。go/ご/合成入力、10連打、各入力のパルス再発生、文字/当たり判定の浮遊追従、2分率と寿命の回帰を含む。
