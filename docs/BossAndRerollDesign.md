# ボス遭遇とリロールのドロップ

2026-11-05。ユーザー指定のRepeaterエンドレス拡張。既存の入力、通常敵分布、11サブ武器、進化、ストリークを維持する。

- [Cypher公式紹介](https://steamdb.info/patchnotes/15604957/)：周囲の敵の文字を変える能力と、掲載GIFの高速に変わる文字群・広い範囲円を確認。ユーザー指定を優先し、元の仮名の並べ替えでなく同じ読み文字数のランダムな仮名へ変更する。
- [日本語Wikiのジェミニ](https://wikiwiki.jp/glyphica/ジェミニ)：約6秒の接近中に連打で防御する動作。
- [日本語Wikiの詩人](https://wikiwiki.jp/glyphica/詩人)：眼のようなUI、詩の全文入力、文字の塊の遅い弾、敵への二重入力付与。眼の外観は[公式Steamスクリーンショット](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/2400160/ss_cdd249dc74d96291c52d4baadad2f829f6a42c67.1920x1080.jpg)も目視した。
- [公式Wiki](https://alias.black/glyphica/wiki_english.html)：Re-Roll取得で回数が増えること、ドロップが存在することを確認。平均120秒はユーザー指定であり公式のドロップ率と主張しない。

公開資料に見つからないHP・回復速度等は以下のローカル調整値と分ける。画像自体は製品へ貼らず、SVGとCanvasで独自に再構成する。

## 到着・説明・時間停止

初回240ゲーム秒、その後480、720秒…で遭遇する。順番はGemini→Cypher→Poetの循環を暫定採用。登場直前にCombatSessionが更新を境界時刻で止め、スマホ幅に折り返す説明と英字goを表示。goは灰色の角丸矩形に背景色の文字で描く。日本語の読み「ご」を共有WordMatchEngineの別インスタンスで判定する。表示だけgoに固定し、英字go・仮名ご・IMEのごへの合成置換を受理する。物理的な打鍵を捏造したり、デコーダーを英字へ書き換えたりしない。Spaceやタップでは開始しない。開始/終了時にinputEpochでIME境界を切り替え、goを戦闘・ストリークへ持ち込まない。

説明中・報酬選択中は敵、弾、寿命、D.O.T.、バフ、触手、詩人弾、ドロップ判定、次ボスのゲーム時刻をすべて停止する。既存ボスが残っている間は次ボスを重ねない。倒した時点で期日を過ぎていれば次の説明を出し、開始後の次回は未来の4分境界へ進め、過去のボスをまとめて消化しない。撃破でエンドレスを終了せず通常戦闘を続ける。

## ボスの構造

BossDirectorがスケジュールと独立した本体を管理し、BossEncounterBehaviorに沿ったGeminiEncounter/CypherEncounter/PoetEncounterがそれぞれの行動・触手・暗号範囲・詩の進捗・弾を所有する。EnemyDefinition.bossKind、EnemyKind.BOSSで通常種の自然抽選と分ける。Gemini/Cypherは共通ダメージ経路・武器の標的になる。PoetはUIの入力対象で、弾の衝突や自動武器の標的にはならない。BossRenderer/EnemyRendererは状態を描くだけで入力・攻撃・回復を決めない。

生存上限16にはボス本体とSplitter全部品も含める。満員でボスが入る場合だけ、プレイヤーから最も遠い通常個体を必要な枠数まで退場させる。XP・撃破数・ドロップは与えず、入力中の語は既存の死亡時退役規則で継続可能にする。ボスのために上限を超過させたり、登場を空き待ちで遅らせたりしない。

Geminiは独立HP12000の本体2つと別々の語を持つ。HPが低い側だけ、相方のHPを超えない範囲で毎秒75HP回復する。同じHPなら増えず、死亡した体は復活させない。12秒ごとに触手攻撃を開始し、6秒以内に一文字を10回完成すれば反撃成功。失敗時60ダメージ。あ/い/う/え/おから一文字を選び、入力方式に応じて仮名またはa/i/u/e/oを表示する。専用キー入力ループではなく通常の共有判定に短い目標を追加する。触手は目玉を覆わず内側の体の縁から伸び、先細りにする。10回成功時は0.24秒で体へ引き戻す。連打回数の数値カウンターは表示しない。有効入力ごとに円と文字を0.22秒の短い拡縮で跳ねさせる。最後の入力時も引き戻し中に反応を表示する。本体は左右それぞれの定位置から横4dp・縦6dpの範囲を周期的に漂い、文字/HP/衝突も同じ位置へ追従する。

CypherはHP5000。ゆっくり画面内を移動し、短辺の42%を半径とする範囲内の通常敵の語を変更する。本体自身も暗号語を持つ。小さな赤い中心円（当たり判定半径5dp）を覆うように、20個の小文字a–zを中央へ密集させる。文字サイズは15–17dp、約30Hzで瞬時に切り替え、フェードや補間は使わない。見た目の半径18dpで入力語との間隔を確保する。正式表記にも生成したひらがなを表示し、「暗号」というラベルは使わない。入力対象の語は毎フレーム変えない。入場・退場時と入力完成後にだけ新しい語を生成。読みのUnicode文字数を保存し、通常のja言語グラフでtsuse/tuse/tuce等を受理する。文字変更はremoveWord/addWordの観測境界を使い、過去の未確定IMEを新しい語へリプレイせず、他の語の入力進捗とストリークを壊さない。

Poetは日本語Wiki掲載の、公有の夏目漱石『吾輩は猫である』冒頭を使用する。24の句へ区切り、全文を打ち終えると倒れる。完了した句をチェックポイントとして保持し、現在の句だけ既存判定へ参加させる。周囲の通常敵へ入力を切り替えられる。原文・読み・文字進捗は別に持ち、長いローマ字は現在位置へ横スクロールする。5秒ごとに最大3体へ遅い弾を発射し、固定発射方向の経路上で最初に当たった敵へwordSealedを付ける。四角枠と²を表示し、最初の完成は封印解除だけ。同じ語を再登録し、2回目の完成で主武器/サブ武器が反応する。詩人撃破時に封印と残弾を消す。固定の詩の題名は表示せず、進捗は割合だけを表示する。句の背景は灰色の横方向グラデーションで、中央40–60%は不透明度約75%、左右端は透明にする。詩人が生存する間だけ自然出現率を通常の75%にし、出現辺を左・右・下へ限定する。各到着で辺を一度選んでから、その辺の候補位置を最適化する。これにより下辺への偏りを避ける。撃破後は通常の率と4辺へ戻す。

これらのHP・12秒・60ダメージ・速度48dp/秒は調整可能なBossBalanceのローカル値。10連打・6秒・5秒周期・読み文字数維持は指定仕様。繰り返しの遭遇でもHPはこの定義値を使う。

## リロール

敵の実撃破をドロップ機会とし、ゲーム時間で平均120秒のランダム到着時刻を決める。待ち時間は平均30秒の指数分布を4つ足したErlang(shape=4)、平均120秒・標準偏差60秒。以前の殺害間ハザードも設定平均120秒だったが、指数分布は短時間の連続ドロップが多いため、この分布で短い間隔への偏りを抑える。固定120秒間隔や最低待ち時間は設けない。期限が来た後の最初の通常敵の撃破で1個だけ落とし、その実時刻から次の待ち時間を抽選する。同じ時刻の多重撃破・長い無撃破期間の後も未発生分をまとめて配らない。撃破待ちの離散化分だけ実際の平均間隔は120秒よりわずかに長くなる。ボス本体やプレイヤー接触による消失では落とさない。

既存CombatPickup/共有WordMatchEngineを利用する。ダイスSVGと、飛び出して揺れながら上昇する小さな四芒星を描く。煙の円形粒子やグラデーションは使わない。入力語はgoと同じ灰色角丸矩形/背景色文字で表示する。リロールだけは矩形の外側・上に正式表記を表示し、goには正式表記を追加しない。残りリロール数の常時HUDは表示せず、アップグレード選択画面の回数表示は維持する。寿命は10ゲーム秒。ダイス・読み・正式表記・入力枠・寿命バーの寸法と間隔は従来の60%。未入力文字は背景色、入力済みは薄い灰色に変え、入力進捗の下線を描かない（goも同じ色変化）。星は毎秒7個、寿命0.18–0.28秒、速度90–130dp/秒、大きさ2.4–4.6dpを基準にばらつかせ、ダイスの左右から狭い上向きの範囲へ飛ばす。短命な星が入力ラベルの裏に全部隠れないよう、文字の後に星を重ねる。付いた語を完成すると一周のrerollsRemainingを1増やし、語と本体を除去する。武器は発動しない。初期3回は維持し、追加分に上限は設けない。期限切れ時は語も消し、二重回収できない。
