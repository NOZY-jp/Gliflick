# 戦闘エンティティ・武器設計

状態: ドローンの7段階ティアと巨大化・加速化の排他的な突然変異、ティア形状差、個体サイズを実装済み。ほかの敵・派生形態は設計段階。
更新日: 2026-10-30

## 目的と範囲

敵・プレイヤー・弾が動き、文字完成で標的へ弾を撃ち、衝突によってHPが変化するシューティングゲームを作る。現行の最小実装・公開パラメーターの出典・拡張の境界は [EndlessCombatDesign.md](EndlessCombatDesign.md) を正とする。本書は他の敵種を含む全体要件を保持する。

本書は、ユーザーが決めた要件、Glyphicaの公開情報から参考にする挙動、このプロジェクトでは簡略化する範囲、未決事項を区別する。公開情報はゲーム内部の実装方式を示すものではないため、クラス構成や物理処理をそのまま再現しない。

## 用語とオブジェクト案

形状・敵の役割・強化形態を一つのIDに押し込まず、別の概念として扱う案を置く。実際のID設計、継承関係、interfaceの切り方は実装前に確定する。

| 概念 | 責務・候補データ |
| --- | --- |
| Player / MainWeapon | メイン武器を兼ねるプレイヤー本体。初期パラメーターはHPのみ。見た目は円の輪郭。 |
| Enemy | 敵1体の実行時状態。敵種ID、バリアントID、形状ID、位置、速度、現在HP、与ダメージ、表示文字などを持つ候補。シールド付き敵は現在シールド値も持つ。 |
| EnemyDefinition | 敵種・バリアントごとの固定値を定義する候補。最大HP、速度、ダメージ等を持たせ、個体ごとの現在HP・位置とは分ける。 |
| Repeater | メイン武器。標的への発射を制御する。初期レベルは1。 |
| Projectile | 弾1発の実行時状態。発射元、位置、速度、ダメージ、当たり判定などが候補。Repeaterの弾とシューターミサイルを同じ弾クラスにするかは未決。 |
| WarderBarrier | ウォーダーに紐づく回転バリア。敵本体とは別の衝突エンティティとして扱う案。所有者死亡時に消滅する。 |

現在は`EnemyKind`（役割）、`EnemyVariant`（形態）、`EnemyShape`（外形）を分離。固定値は`EnemyDefinition`、個体の行動は`EnemyBehavior`、耐久値処理は`Durability`へ分ける。実装済みの敵種はDRONE / NORMALで、ティア・形状・突然変異を独立した定義値として選ぶ。各`Enemy`は数値の`size`を持ち、基準半径に掛けた有効半径を衝突と描画で共有する。Droneの中心円はTier1〜4で同寸、外周の円が増えるTier1〜3で全体の半径が広がり、Tier3以降は同じ外半径を保つ。文字と耐力バーは位置だけサイズに追従し、文字サイズとバー寸法は固定する。被弾円はヒット時の有効半径を基準に拡大する。武器は`MainWeapon`契約と個別の設定・発射方式へ分ける。`EnemySpawnPolicy`は敵定義を選び、`EnemySpawnDensity`は確率的に一回一体の出現を決める。群れ数・出現間隔は持たない。Threatは値と効果が未定義の拡張用モデルとして残す。

## 敵の要件

| 敵 | このプロジェクトでの要件 | 公開情報から参考にする点 |
| --- | --- | --- |
| ドローン | 基本敵で、出現率を最も高くする。プレイヤーへ向かって直進する。低確率で巨大化または加速化する。巨大化はHPを3倍、加速化は速度を2倍にする。二つの強化は同時に付けない。実装では変異の合計確率5%（各2.5%）、巨大化の数値サイズ1.5倍を用いる。ティアごとの円形マーカーは公式Wiki画像をベクターで再現する。 | 公式Wikiもメイン武器へ向かって移動すると説明し、EnlargedはHPを3倍、Hastenedは移動速度を2倍としている。変異率・数値サイズ倍率は非公開。 |
| シールドドローン | ドローンの系統。シールド値を持ち、攻撃を受けなくなるとゆっくり回復する。 | 公式Wikiではドローンの派生敵で、HPと別のシールドバーを持ち、一定時間ダメージを受けないとシールド回復が始まる。回復開始までの時間・回復速度は公開記述に数値がない。 |
| シューター | プレイヤーから離れた位置で停止し、ミサイルを発射する。 | 公式Wikiではレベルの端で停止し、耐久力のある弾をメイン武器へ向けて撃ち続ける。停止条件は本プロジェクトでは「プレイヤーから一定距離」とする案で、画面端方式と同一とは限らない。 |
| シューターミサイル | シューターが発射する。ドローンと同等の性能を想定するが、「同等」がHP・速度・ダメージ・当たり判定のどれを指すかは未確定。 | 公式Wikiはシューターの弾を耐久力のある飛翔体として説明するが、ドローンと同じ性能とは説明していない。 |
| ウォーダー | 周囲をゆっくり回転するバリアを展開し、近くの敵を無敵にする。ウォーダー死亡時にバリアも消える。 | 公式Wikiでは向いている方向からのダメージを防ぐ回転シールドと、生存中に近くの敵を無敵にするオーラが説明される。 |

### ウォーダーバリア

- ウォーダーの周囲をゆっくり回転する。
- 無敵で、ウォーダーが死亡すると消える。
- 周囲120°の弾を消す、というのが本プロジェクトの希望仕様。
- 近くの敵へ無敵効果を与える。
- 敵本体ではなくエンティティとして扱う案。

公式Wikiは「現在バリアが向いている方向からのダメージを防ぐ」と説明するが、扇形の角度が120°であることや、弾オブジェクトを消去する実装までは確認できない。120°と弾の消去は本プロジェクト独自の仕様として扱う。無敵効果の範囲・対象・バリアとの持続関係は未確定。

## メイン武器と弾

### Repeater

- 今回実装するメイン武器はRepeaterのみ。
- レベル1では、標的に向けて3発の弾を発射する。
- 武器レベル、弾数、ダメージ、爆発効果などの強化は後回し。
- 公式Wikiは短いバースト発射を説明する。初期3発はユーザー指定で、2026-10-30に確認した日本語コミュニティWikiにも3発・基本ダメージ35の掲載がある。出典と採用値は[EndlessCombatDesign.md](EndlessCombatDesign.md)。

### 弾の挙動と見た目

- 弾は比較的速いが、目で追える速度にする。
- 見た目は小さな円と細いトレイル。各弾は発射時に決めた方向へ直進し、敵との最初の衝突または画面外で消える。
- 弾は標的へ向かうが、発射元と標的の間に別の敵やウォーダーバリアがあれば、そちらが先に弾を受ける場合がある。
- 標的選択と実際の被弾対象を分け、移動する円同士の相対スイープ判定で最初の衝突を解決する。

## 文字と標的の接続

- 敵は表示文字を持つ。
- 文字を正確に入力すると、その敵がメイン武器の標的になる。
- 標的になったとき敵の文字が別の文字へ入れ替わる。
- `CombatSession`が共有の`WordMatchEngine`と`GameImeEditText`へ接続する。単語完成は撃破ではなく3連射の予約と文字の再割当て。複数完成はFIFOのバースト待ち列で受ける。
- 標的死亡後も予約弾を発射し、入力途中の死体文字だけは既存の入力が完了・失敗するまで追跡する。新しい語頭候補、発射、報酬には使わない。
- 入れ子・同時完成・部分重複による複数語完成とoverlapEventsの接続点を実装済み。共有入力と別々に入力した二語を区別し、複数標的化はFIFOのバースト待ち列で受ける。詳細は[MistypeDesign.md](MistypeDesign.md)。ダメージブースト本体は未実装。

## 参考にする公開仕様と取り込まない複雑性

公開されている[Glyphica Wiki](https://alias.black/glyphica/wiki_english.html)は、時間で増えるThreat、EndlessにおけるThreatとプレイヤーレベル由来の適応値の比較、特殊・エリート敵のクラス上限を説明している。[開発者インタビュー](https://redharegames.wordpress.com/2025/02/03/game-talk-glyphica/)もThreatの式が敵の難易度と密度を進行させることを示すが、計算式や出現数への換算値は公表していない。本プロジェクトはその未公開式を推測せず、Threatを未使用の型として保持する。出現数のプレイヤーレベル補正はプロトタイプ独自の調整値で、原作式の再現とは扱わない。

参考値として、公式Wikiの敵バリアント一覧には次の範囲が掲載されている。初期バランス値として採用したものではない。

| 参考対象 | Wiki掲載値の範囲 |
| --- | --- |
| ドローン | HP 80〜5,800、ダメージ 40〜210 |
| シールドドローン | HP 100〜2,400、シールド 200〜4,800、ダメージ 50〜250 |
| シューター | HP 300〜7,200、ダメージ 25 |
| ウォーダー | HP 300 |

出典の表は複数のバリアント値を列挙している。本プロジェクトでは最初に必要な種類・バリアントだけを選び、ゲームが成立する少数の値で開始する。出現密度は独立した`EnemySpawnDensity`の暫定値で、毎tickの確率から一体ずつ出す。群れ・固定間隔の概念は持たない。Threatの増加やプレイヤーレベルとの比較式は未実装。武器強化ツリー、状態異常、他の敵種は後回し。

## サイズとティア外形

- `EnemyDefinition.radius`は基準半径、`EnemyDefinition.size`は個体へ渡す数値サイズ倍率、`Enemy.radius`は両者の積で求める有効半径。
- 接触・弾衝突、画面外スポーンの余白、敵本体、被弾円・飛散エフェクトに有効半径またはサイズ倍率を使う。Tier1/2/3の全体サイズは1/2/2.83。Tier4〜7はTier3と同じ2.83。巨大化変異はさらに1.5倍。
- 文字と耐力バーは敵の大きさに合わせて表示位置を離す。文字サイズと耐力バーの幅・高さは敵サイズで変えない。被弾円はヒット時の敵の有効半径から始まり、その半径に比例して120%まで拡大する。
- ティア1〜7のマーカー形状は公式Wiki画像とユーザーの説明に合わせる。中心円はTier1〜4で一定サイズ。Tier2/3は外周リングを足し、Tier4は2・3段目のリング間を塗り、Tier5は中心円相当の穴を開ける。Tier3以降の外半径は同じ。
- ドローンの基本移動速度は5.95dp/s（以前の8.5dp/sの70%）。加速化形態はこの基本値の2倍。
- `DroneTierDistributionPolicy`は開始60秒をTier1のみとし、その後Tier2を長い時間幅でなめらかに加える。Tier3以降はボス撃破通知ごとに一段階ずつ解禁する。現在ボス自体は未実装なのでTier2までに制限される。個々のスポーンで抽選し、レベルアップ時に既存敵の能力を変えない。公開されていないThreat式を再現したとは扱わない。
- 同時に生存する敵は`CombatConfig.maxEnemiesAlive`で制限し、現行値は16体。満員中は新たな出現を行わないが、グループ出現や固定インターバルには戻さない。

## 実装時の確認項目

- ドローンはプレイヤーへ向かって移動する。
- 巨大化ドローンのHPは基準の3倍、加速化ドローンの速度は基準の2倍で、同時には発生しない。
- シールドドローンは被攻撃停止後にシールドを回復する。回復タイミングと速度は採用値を別途決める。
- シューターは指定条件で停止し、プレイヤーへミサイルを発射する。
- ウォーダーの生存中は範囲内の敵が無敵になり、所有者死亡時にバリアが消える。
- Repeaterは標的に3発発射する。現行の採用値・暫定値は[EndlessCombatDesign.md](EndlessCombatDesign.md)を参照。
- 弾の実際の進路上に敵やバリアがあれば、標的とは別の相手に衝突できる。
- 衝突時に適切なHPまたはシールドが減り、プレイヤーのHPも敵側の攻撃から変化する。
- 敵・弾・バリアの更新と描画を分け、画面座標上の形状だけで戦闘ルールを決めない。

## 未決事項

1. 幾何形状と4種類の敵の対応、`typeId`・`variantId`・形状IDの意味。
2. シールドドローンやシューターなど後続の敵のHP、速度、接触ダメージ、出現率。
3. 公式WikiにないドローンTier 8・9のHPと接触ダメージ。公式Update 12は2段階追加を述べるが、公開テーブルに数値がないため未実装。
4. シールドのダメージ吸収順、回復停止時間、回復速度。
5. シューターの停止距離、ミサイルの性能・速度・ダメージ・発射間隔と、ミサイルをEnemyとProjectileのどちらとして分類するか。
6. バリア120°の角度の取り方、回転速度、弾の消去条件、無敵オーラの半径と適用対象。
7. 公開情報で確定できなかった弾速・弾サイズ・発射間隔の今後の調整。現行値は定義データへ集約済み。
8. 現行は接触でドローンを消費しHPを減らす。HP0で停止・タップ再開。将来の無敵時間や追加攻撃の仕様。
9. 現行は生きた敵で使っていない読みを優先してランダム再割当て。将来の語難易度・種類別辞書。
